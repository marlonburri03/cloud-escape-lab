Lösungsübersicht

Hub-and-Spoke: Connectivity Subscription (Contoso Landing Zone) + Escape-Room-Subscription mit Azure Container Apps

Trennung Plattform-Stack / Theme-Stack erwähnen. Ingress/Egress via zentrales Application Gateway / Azure Firewall.

GitLab Pipeline

main
 ├── feature-<beschreibung>
 ├── fix-<beschreibung>
 └── hotfix-<beschreibung>

Entwickler → Merge Request (Lint & Security) → main
        → Pipeline: Plan → Apply → Build → Scan → Deploy

Secretless Deployment via OIDC Federated Credentials. Releases über Tags (MVP, MLP, MMP).

Betonen: Pipeline als technisches Merge-Gate, keine manuellen Portal-Änderungen.
