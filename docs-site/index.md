# Cloud Escape Lab

Diese Seite ist die öffentliche Dokumentation der Semesterarbeit
**Cloud-based escape room platform**.

Sie wird von GitLab Pages aus dem `main`-Branch gebaut und unter
[<your-gitlab-group>.gitlab.io/3-semester/cloud-escape-lab](https://example.gitlab.io/presentation/)
veröffentlicht.

## Inhalte

- **[Konzept](concept.md)** – das vollständige Projektkonzept inklusive Aufgabenstellung,
  Projektplan, Lösungsdesign, Pipeline und Branching-Strategie.

## Repository

Der gesamte Quellcode, die Infrastrukturdefinitionen sowie die Pipelines sind im
zugehörigen GitLab-Projekt versioniert:
[gitlab.com/<your-gitlab-group>/cloud-escape-lab](https://gitlab.com/<your-gitlab-group>/cloud-escape-lab).
